# Sarvam AI Playground

A collection of small apps built while learning to work with Sarvam AI's Indian-language models, following Loop Kaka's YouTube lecture series.

## What's inside
- **Chatbot**: conversational bot powered by Sarvam-105B
- **Role-based chatbot**: the same bot with configurable personas/system prompts
- **Translation app**: translate between Indian languages and English
- **Text-to-Speech**: speech generation using Bulbul

## Models used
- Sarvam-105B (chat and translation)
- Bulbul (TTS)
